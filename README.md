# sft-trading-dataset

A data-collection and labeling strategy for supervised fine-tuning (SFT) of an LLM on trading reasoning (交易思路): given market context, the model produces a reasoned thesis and structured trade decision. This repository contains the design specification and a proposed pipeline skeleton — it is intentionally incomplete pending scope confirmation on instruments, data sources, base model, and outcome-label availability.
